# Changelog

## 0.1.0

- Style key, value and prop completion; hovers; style checks with quick fixes.
- Color swatches and picker for Python color strings and `[tool.pyxpo]` hex colors.
- `[tool.pyxpo]` completion, hovers and `pyxpo config` errors in pyproject.toml.
- Run, prebuild, doctor, config and create commands; status bar menu.
- Convert style keys between camelCase and snake_case.
- Snippets.
- Auto-import of pyxpo names from completion, quick fixes and `pyxpo: Add Missing pyxpo Imports`.
- Works in Restricted Mode (untrusted folders); config validation and run commands need trust.
